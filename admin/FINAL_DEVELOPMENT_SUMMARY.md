## 🐛 已知问题和技术债务

### 技术债务
1. **API响应格式不统一**
   - 媒体API: `{ success: true, data: { data: [], total } }`
   - 文章API: `{ data: [], total, page, limit }`
   - 建议: 统一后端响应格式或前端拦截器处理

2. **类型定义需要整合**
   - `PaginatedResponse` 和 `ListResponse` 共存
   - 建议: 合并为统一的分页响应类型

3. **错误处理可以更细粒度**
   - 当前: 简单的 `message.error()`
   - 建议: 根据错误码显示不同提示

### 改进建议
1. **添加自动保存指示器**
   - 显示"已保存"、"保存中"状态

2. **增强图片处理**
   - 上传前预览
   - 图片压缩
   - 裁剪功能

3. **富文本编辑器增强**
   - 代码高亮
   - 表格支持
   - 视频嵌入

4. **批量操作优化**
